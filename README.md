# 💸 Tahweelati Express | تحويلاتي إكسبريس
> **Cross-Border Mobile Currency Exchange & Transfer App Prototype**
> 
> A modern, responsive, and secure FinTech UI/UX prototype built with **Flutter** and **Dart**, designed for seamless cross-border money transfers, real-time currency conversion, and automated e-KYC workflows.

---

## 📌 Project Overview | عن المشروع

**Tahweelati Express** is a mobile application prototype designed to streamline peer-to-peer and cross-border currency exchanges. The project addresses key friction points in traditional remittance systems by offering an intuitive interface, transparent dynamic rate calculations, automated verification concepts, and transaction tracking.

> **Project Status:** 🚀 **UI/UX & Functional Front-End Prototype (MVP)**  
> *This repository contains the full mobile front-end application written in Flutter. Backend integration, live currency APIs, and production database setups are planned for future releases.*

---

## ✨ Key Features & Functionalities | المميزات والوظائف

- 📱 **Modern FinTech UI:** Sleek, responsive, and intuitive interface designed for financial transactions.
- 🆔 **e-KYC Verification Concept:** Integrated camera capture interfaces for passport scanning and biometric face matching during registration.
- 💱 **Multi-Currency Calculation Engine:** Live currency conversion calculations supporting major currencies (USD, IQD, SDG) with instant fee deduction previews.
- 📑 **Transaction Confirmation & Receipt Generation:** Unique reference ID generation (`TRX-XXXXXX`) for completed transfers.
- 📜 **Transfers Audit Log:** Dedicated transaction history screen listing past remittances with precise timestamps and recipient account details.
- ⚙️ **Account Management:** Profile settings featuring verified account status badges, bilingual localization options (Arabic/English), and secure logout workflows.
